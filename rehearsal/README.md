# Wheels & Bones — browser build

Educational wheelchair-repair game (English). Playable at https://fordragon88.github.io/wheels-and-bones-test/rehearsal/

This repository contains only the built web version:

- `/` — the game (Godot 4, WebAssembly): `index.html`, `wnb-engine-*`, `wnb-*.pck`, `frames/`, `music/`.
- `/classic/` — the previous version (pygame / pygbag), kept as a fallback.
- `wheels_and_bones.apk`, `wheels_and_bones.tar.gz`, `anim/`, `turntable/` in the root — files of the previous version for pages still open or cached in browsers; they will be removed later.

Keyboard controls: arrows, Tab, Enter; F1 — help. Screen readers read the game through a live region on the page.
